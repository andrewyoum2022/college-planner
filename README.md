# 우리 가족 미국 대학 원서 플래너

2027년 가을 입학을 준비하는 가족용 웹페이지입니다.

## 사용 방법

브라우저에서 `index.html`을 열면 됩니다. 입력한 내용은 해당 브라우저에 저장됩니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub의 `college-planner` 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 고릅니다.
3. `main` 브랜치와 `/(root)` 폴더를 선택합니다.

배포 뒤에는 `https://andrewyoum2022.github.io/college-planner/`에서 열 수 있습니다.

> 주의: GitHub Pages는 공개 사이트입니다. 학생의 생년월일, 여권/비자 정보, 세금 자료, 연락처 등 민감한 개인정보를 이 저장소나 페이지에 넣지 마세요.

## 공동 편집

현재 버전은 각 기기 브라우저에 따로 저장됩니다. 두 사람이 실시간으로 같은 데이터를 수정하려면 Firebase 또는 Supabase 같은 공유 데이터 저장소를 연결해야 합니다.
